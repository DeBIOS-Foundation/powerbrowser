<objective>
Apply Chris's G-23 decision (23-CONTEXT, verbatim: "Cut at 60 while typing (Recommended)"): Save as
Mode and Save Setup stop at 60 characters while the user types or pastes, the way group rename
already does. No new copy. 14-UI-SPEC states the rule (MODE-02, ROADMAP criterion 2).

Purpose: today both services call `quickInput.input(...)` and slice after it resolves, so the user
sees a longer name accepted and silently shortened (G-14.1.1-23). Theia 1.76's `InputOptions` has no
length option, so the stock route is `createInputBox()` with an `onDidChangeValue` cut (research).
The two live checks that save a mode or a setup stub `quickInput.input`, which the services no longer
call, so they change in this plan, and Chris re-locks them if they are hash-locked.

Output: one helper, two one-line call-site changes, one static check and one live check with three
registry rows, three 14-UI-SPEC lines, two ng stub updates, the wave-1 quick gate, and (if needed)
Chris's re-lock.
