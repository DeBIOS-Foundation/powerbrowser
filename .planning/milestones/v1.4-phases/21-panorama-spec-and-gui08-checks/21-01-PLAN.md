**1. Write `scripts/lib/ui-spec.mjs`** (ESM, Node standard library only, no `main()`; header comment: shared by verify-gui08-panorama-copy and verify-gui08-canvas-geometry; a parse change here changes both). Named exports:
- `specSection(src, heading)`: the text from the line that is exactly `## {heading}` up to the next line starting `## `, or `''` when the heading is absent or occurs more than once.
- `tableRows(text)`: one trimmed cell array per table body row. A row is a line starting `|`; separator lines (every cell `:?-+:?`) and the header line directly above a separator are skipped.
- `boldLiterals(text)`: every `**"…"**` content, lazily matched (the gui09 regex), in order.
- `copyContract(spec)`: `{ contract, retired }`. The Copywriting Contract section is split at the line exactly `### Retired copy`. Each part's literals are `boldLiterals` over the cells after the first of each table body row. Prose lines are never read.
- `normaliseSlots(s)`: `${…}` and `{word}` both become `{}`.
- `geometryRows(spec)`: from the Canvas Geometry section, `{ consts, css }`. A const row's Key cell is identifiers joined by ` × ` (pattern `^[A-Za-z][A-Za-z0-9_]*( × [A-Za-z][A-Za-z0-9_]*)*$`), giving `{ key, names, numbers }`. A CSS row's Key cell is a backticked selector, a space and a property (``^`(\.[a-z][a-z0-9-]*)` ([a-z-]+)$``), giving `{ key, selector, property, value }`. Numbers are every `\d+(?:\.\d+)?` in the Value cell before its first `(`. Any other row is prose and is not compared.
- `typography(spec)`: sorted unique `{ sizes, weights }` from the Typography table body rows: sizes are every `(\d+)px` in cell 2, weights every `\b[1-9]00\b` in cell 3.
- `stripCssComments(css)`; `ruleBodies(css, selector)`: the body of every rule whose whole selector list is exactly `selector` (rules inside `@layer` and `@media` included).
- `topLevelNumericConsts(src)`: Map of name to expression for lines `^(export )?const NAME = <number | [numbers] | Math.round(A * B)>;` with NAME in SCREAMING_CASE.
- `resolveConst(name, texts)`: every `const NAME = expr;` definition across `texts` (any indentation); when there is none, every `NAME: <number>` property. Evaluates a number, a number list, or exactly `Math.round(A * B)` with A and B resolved the same way; any other form, or no occurrence, returns `{ error }`. Several occurrences must agree, else `{ error }`.
- `geometryDiff(spec, sources, { canvasRels, cssRel })`: failure strings, each naming the row key and identifier or selector:
  - (a) ZERO const rows or ZERO CSS rows is a broken instrument.
  - (b) A const row whose names and numbers counts disagree is malformed. One name against several numbers compares a list const.
  - (c) Each name is resolved over every non-CSS source; a value other than the spec's names both.
  - (d) A CSS property must be declared in exactly one of its `ruleBodies` over the comment-stripped CSS, as `{n}px`, equal to the spec value.
  - (e) Every `topLevelNumericConsts` name in a `canvasRels` file without a const row is `undeclared canvas constant {NAME} ({rel})`.
