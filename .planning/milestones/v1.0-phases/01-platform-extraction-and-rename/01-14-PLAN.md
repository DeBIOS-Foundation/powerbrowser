DECLARATION sites, and say nothing about the identifier bound at a `this._showError()` CALL site.

value. There is no live user-facing leak. The gap is that the gate structurally cannot fire on the
shape it exists to catch, which CLAUDE.md's Verification section makes a correctness property in its
own right: a check that can only go green is not a check.

fire-and-forget promise root in the shell (four confirmed call sites: the bootstrap's start call,
the Retry control's retry call, and the two long-lived loops). It is exactly the site where a future
edit plausibly passes a caught exception's `.message` instead of a table key, and today's gate would
wave it through into full-screen user-facing text.
