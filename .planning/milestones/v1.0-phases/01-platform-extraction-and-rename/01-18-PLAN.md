<objective>
Close UAT gap G-01-3: the About dialog still shows the stock Mozilla community,
donation, licensing, terms, and privacy link rows.

The diagnosis is an AND-gate. Upstream `aboutDialog.xhtml` hard-codes every one of
those rows as a literal `href` — no pref is consulted, so `firefox-branding.js`
cannot suppress them. And the one branding-side suppression channel upstream does
provide, `chrome://branding/content/aboutDialog.css`, is inert: both variants'
`content/jar.mn` are stale stubs packaging only the five icon PNGs, so the
`aboutDialog.css` that has existed in both branding directories since 01-03 never
ships and 404s silently. Fixing the packaging side — the half inside this tree's
rebrand surface — opens the suppression path and, as a side effect, finally
applies the dark-neutral restyle that file was written to carry.

Purpose: the About dialog is the product's single most-read branding surface, and
it currently sends a user who clicks a link labelled with this product's own
vendor name to another vendor's site.
Output: a packaged, live branding stylesheet that suppresses the stock rows; a
derived, bidirectional packaging-completeness assertion in `--quick` so a
resource can never again sit beside a manifest that forgot it; and a built-tree
proof that the resource ships.
</objective>
