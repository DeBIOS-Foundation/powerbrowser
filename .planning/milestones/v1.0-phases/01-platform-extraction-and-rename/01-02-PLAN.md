| Boundary | Description |
|----------|-------------|
| Gecko chrome → Node backend | The auth token and the supervised flag cross this boundary as env vars; the backend-ready sentinel crosses back as stdout. A one-sided rename breaks authentication silently. |
| privileged chrome → the internals-boundary guard | `check-internals-boundary.sh` allowlists exactly one chrome package. A stale glob widens the guard rather than failing it. |
