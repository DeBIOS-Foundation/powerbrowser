<objective>
**As a** downstream brand author, **I want to** find every asset I am expected to replace in one
`brand/` folder at the repo root, **so that** the rebrand surface really is "one config file plus
one assets folder" and not a scavenger hunt through the platform tree.

This plan moves the source mark to its permanent home and carries its one reader with it. It has
no dependency on the generator and touches no file any other plan in this phase touches, so it
runs in parallel with the tracer.

Purpose: CFG-01 promises `configuration.toml` plus a `brand/` assets folder. Without this move,
`brand/` does not exist and half that promise is unmet.

Output: `brand/mark.svg`, and a `verify-branding-preflight.mjs` that still asserts exactly what it
asserted before, about a file that now lives somewhere else.
</objective>

      - line 467, the `readText(root, …)` argument — the actual read;
      - line 470, the failure string reporting the file does not exist;
      - line 477, the failure string reporting no single-line svg element to compare against;
      - line 482, the failure string reporting the mark and the Theia constant have drifted;
      - line 487, the failure string reporting the mark is not square;
      - line 490, the failure string reporting the mark has lost its dual fill;
      - line 633, inside the `--self-test` fixture copy list. This is a second, structurally
        separate site from the block above and is the one that gets missed. The self-test copies
        the listed paths into a temp tree, so a stale entry makes the fixture tree lack the file

    file set from `git ls-files`, and an unstaged path change is invisible to it. The SVG extension
