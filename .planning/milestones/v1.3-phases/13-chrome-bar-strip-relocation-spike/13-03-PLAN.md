| Boundary | Description |
|----------|-------------|
| Address text to URI routing | Typed text becomes navigation through existing open handlers. |
| Suggestion rows to the dropdown | Row fields render beside chrome controls. |
| Bar commands to stock windows | New-tab crosses into a privileged window open. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-03-01 | Information disclosure | markup injection through suggestion titles | high | mitigate | Titles and captions render as text only, proven by the raw-markup grep gate. |
| T-13-03-02 | Information disclosure | internal identifier in user-facing copy | medium | mitigate | Contracted strings verbatim from the UI-SPEC; copy gate stays green; diagnostics carry what copy omits. |
| T-13-03-03 | Tampering | address text as code | medium | mitigate | Commit routes through existing URI routing only with empty as no-op; no evaluation or shell surface. |
| T-13-03-04 | Denial of Service | mode switch losing tabs | high | mitigate | Toggle is selection state only with shell consequences deferred; tab-count chip asserts the invariant on every switch. |
| T-13-03-05 | Elevation of privilege | blocked popup replaced by new UI | low | mitigate | Blocked path reuses the existing throw path; no new dialog, toast, or error surface is authored. |
