<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Chat prompt to ACP child | User text reaches the supervised stdio child at the workspace root. |
| Delegated write to Change Set | Backend-proposed bytes stage as entries; disk writes only on accept. |
| Supervisor env to grandchild | Spawn env must carry no secrets and no re-arming markers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-01-01 | Tampering | proposal writing outside workspace root | high | mitigate | Emitter clamps every staged path to the root and refuses otherwise; negative test in the tracer gate. |
| T-16-01-02 | Information disclosure | token into history or Change Set | high | mitigate | Redaction test over history plus Change Set fixtures; secrets travel the stdin-pipe path only. |
| T-16-01-03 | Elevation of privilege | nested watchdog re-armed via inherited env | medium | mitigate | Scrubbed child env per token-gate precedent; grep gate forbids direct host-env reads in the supervisor. |
| T-16-01-04 | Denial of Service | orphaned child after parent death | medium | mitigate | Die-with-parent plus restart; fail-closed exit 78 before listen without handshake. |
| T-16-01-SC | Tampering | npm installs | medium | mitigate | Sole registry add is the pinned ACP SDK 1.4.0; legitimacy via registry metadata at review. |
</threat_model>
