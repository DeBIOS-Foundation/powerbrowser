## Decisions Made

- **Strip selection, not focus, is the chrome bar's binding key.** `shell.currentWidget` is focus-derived; a web tab's placeholder is under the overlay and never gets DOM focus ("+" focuses the pill, a click lands in the overlay). `mainPanel.onDidChangeCurrent` fires on the strip's selected title, which is what the user sees.
- **Editors show their file URI in the pill** through `NavigatableWidget.getUri`; the registry deliberately excludes editors (docs/URI-SCHEMES.md), so the fallback lives in `addressOf`, not in `uriOf`.
- **Comment stripping in the gate keeps `//` inside regex literals and strings**; without it the derivation of the child's regex-based idioms truncated at the first slash.
- **Live check protocol split into phases** so Node-side `topLevelContexts` / `evaluateIn` reads interleave with page-realm steps; the widget is held on `window.__pbWebTabProbe`.

### Auto-fixed Issues

**1. [Rule 1 - Bug] Chrome -> content replies and pushes never delivered (GUI-DEFECTS item 17)**
- **Found during:** Task 2 (every awaited request timed out; no state push reached the pill)
- **Issue:** Through the actor child's Xray, `win.JSON.parse` is not callable, so `sendResponse` and `receiveMessage` threw on every call.
- **Fix:** Both dispatch sites use the content window's own `JSON.parse` reached through `wrappedJSObject`.
- **Files modified:** powerbrowser/shell/GroupActorChild.sys.mjs
- **Verification:** live check awaited replies and pushes; bridge gate child-purity check green
- **Committed in:** 1416d3c

- **Files modified:** powerbrowser/shell/PowerBrowserAPI.sys.mjs
- **Verification:** live check reads the row back through `searchByPrefix`; internals catalogue green
- **Committed in:** 1416d3c

**5. [Rule 1 - Bug] Pill never followed the page (item 21)**

- **Fix:** Bind to `shell.mainPanel.onDidChangeCurrent`, seeded from `mainPanel.currentTitle`.
- **Files modified:** theia/extensions/chrome-bar/src/browser/chrome-bar-widget.tsx, chrome-bar-commands.ts
- **Verification:** app rebuilt; `--quick` PASS; Chris confirmed in his window

**6. [Rule 1 - Bug] Editor tab showed an empty pill (item 22)**
- **Found during:** Task 3 (Chris, checkpoint)
