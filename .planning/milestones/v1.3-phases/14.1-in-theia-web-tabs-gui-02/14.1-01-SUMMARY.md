## Decisions Made

- Overlay style: CSSOM property writes (`Object.assign(browser.style, …)`) instead of the plan's `style.cssText`. The shell CSS header records that its CSP drops inline style attributes silently; property writes are the path `powerbrowser.js` already uses to toggle the deck. Attribute list, z-index and stacking comment are as planned.
- Live check activation assertion: the plan's `widgetManager.getDescription(shell.currentWidget)` read `undefined` on a correct product because `shell.currentWidget` is the DOM `FocusTracker`'s answer and a headless window never delivers the focus event `activateWidget` raises. The check now records the widget `openUrl` returned and asserts it is both in the main-area titles and a dock's `currentTitle` (Lumino state).
- Embedder wall placement: inside `groupSenderIsTheia` (shared by every kind) as the plan directed; the gui08 gate's `if (!groupSenderIsTheia(actorRef))` anchor is byte-identical and that gate still passes.
- `back()`/`forward()`/`reload()` return `Promise<WebTabReply>` via `channel.request` (Task 3's lost-view rule); the Task 1 fire-and-forget shape was interim.
- Widget `Event` typing: Theia's `Event<T>` imported as `TheiaEvent` to keep DOM `Event` for listener parameters.
