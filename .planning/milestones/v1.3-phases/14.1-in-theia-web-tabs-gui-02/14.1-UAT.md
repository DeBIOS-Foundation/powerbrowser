## Tests

### 1. Embedder wall rejects an in-overlay sender
expected: A page loaded inside a web tab cannot issue webTab* requests; only the primary Theia frame is honoured. An attempt from inside an overlay is refused and logged, never acted on.
result: [pending]

### 2. Two web tabs on one URL
expected: Opening the same address in two web tabs gives two overlays, both rendering, and one store row (documented ceiling A18); closing one leaves the other intact.
result: [pending]

### 3. Continuous panel slide and splitter drag
expected: Dragging a panel splitter or watching the ≤200ms mode-switch slide keeps the page attached to the tab body with no persisting misalignment and no white flash.
result: [pending]

### 4. Chrome-side idempotency
expected: Re-issuing an open for an already-open tab reports already-open without a second overlay; a request for an unknown tab reports unknown-tab and the widget shows the lost-view state.
result: [pending]

### 5. Lost-view rendering and in-flight navigation across a mode switch
expected: A tab whose overlay is lost shows "Power Browser can't show this page right now. Choose Reload to try again, or close this tab." and Reload recovers it; switching mode while a page is still loading finishes the load in place.
result: [pending]

### 6. Typed address while a non-web tab is current
expected: With an editor or view tab active, typing an address and pressing Enter opens a new web tab for it rather than navigating nothing.
result: [pending]

### 7. Two New Tab clicks and the startup strip
expected: Clicking "+" twice gives two "New Tab" tabs, each with its own empty state; a fresh launch starts with no web tabs unless a setup restores them (defect item 24).
result: [pending]

### 8. Pill typing guard against a mid-edit state push
expected: While an address is being edited in the pill, a state push from the page (title or URL change) does not overwrite the edit; Esc restores the committed address.
result: [pending]

### 9. Occlusion by palette, dialog, and menu
expected: Opening the command palette, a Theia dialog, or a menu hides the page under it within a frame and restores it on close; the dropdown case is already confirmed.
result: [pending]

### 10. Many web tabs overflow
expected: Opening enough web tabs to overflow the strip gives stock strip scrolling; only the current tab's page paints, every other overlay is hidden.
result: [pending]
