**A thrown command id became a contracted refusal, the copy gate grew the fifth paint site that can see it (proved by a planted fault the pre-widening gate passed), a comment stopped crediting that gate with an assertion it cannot make, and `reopen()` joined every other reply reader behind one `lostReply` predicate.**

## Accomplishments

- **CR-03 closed as a class, not an instance.** `openDependent`'s refusal was
  `'powerbrowser.setups.open-dependent: … invoke the command again from the command palette'`,
  rendered verbatim by Theia — an internal identifier in user-facing text, and a closing
  instruction naming a command that carries no palette label and therefore appears in no palette.
  It is now `SETUP_DEPENDENT_UNSUPPORTED`, contracted in `14-UI-SPEC.md`, ending on the one
  affordance the user actually has. The gate that guards that file grew paint site 5 — every
  `throw new Error` argument — so the next thrown non-constant string is red before it ships.
- **The widening is proved, not asserted.** Two new fault plants at the throw site: an internal
  identifier put back inside the constant's literal, and a raw literal thrown in its place. Plant
  7 carries a **pre-widening control** — the same scratch copy re-derived with site 5 skipped
  must not see the planted identifier — so the record shows the hole was real rather than merely
  claimed. That control is the live deriver with one site skipped (`opts.throwSite`), never a
  hand-copied replica.
- **WR-02 retired.** `modes.css` claimed `gui09-setups-copy` "goes red on a third" danger
  selector. It does not: it asserts the service tags exactly one dialog and that class has a
  danger-scoped rule here. The comment now states that, keeps the two-selector limit as the
  *design's* limit, and records in one clause why no gate assertion was added — so the next
  reader does not re-open the question and write the forbidden hand-kept list.
- **One predicate decides "lost".** `reopen()` read `reply.ok !== true` inline while
  `lostReply()` also folds `where === UNKNOWN_TAB_OUTCOME`. An `ok: true` reply naming an unknown
  tab read as a successful reopen and left the body blank — the same defect class G-14.1.1-4
  closed one site earlier. `reopen()` now calls the shared predicate.

## Decisions Made

- **No palette label for `SETUPS_OPEN_DEPENDENT`.** The plan's `<deferred_observation>` is honoured
  verbatim: adding a label would put a new entry in the user's command palette, a surface decision
  nobody has made. The copy simply stops referencing an affordance that does not exist.
- **The fifth paint site resolves bare identifiers only.** Anything else at a `throw` goes to
  `unresolved`, which is already a named failure. That is the enforcement mechanism.
- **No enumerated danger-selector list was added to the gate.** Stated in the CSS comment with the
  reason, so the correction cannot be "fixed" later by adding exactly the hand-kept expectation
  CLAUDE.md verification rule 2 forbids.
