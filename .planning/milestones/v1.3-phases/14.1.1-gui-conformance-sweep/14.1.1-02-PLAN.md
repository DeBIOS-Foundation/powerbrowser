## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rendered web page → chrome-side capture | Untrusted page content is rasterised and persisted by privileged chrome code |
| Chrome capture → `tabs.sqlite` thumbnail column | Page-derived bytes cross into the profile store, read back by the Theia backend |
| Private-browsing window → the tab store | Data that must never be persisted at all |
