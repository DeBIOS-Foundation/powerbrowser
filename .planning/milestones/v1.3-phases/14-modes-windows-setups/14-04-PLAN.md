<objective>
Close G-14-1 through G-14-4: the mode switch stops destroying main-area tabs, the shipped toggle segments start reaching the mode service at all, Coding docks its Explorer on every visit, and the launch mode is applied after the shell exists.

Purpose: Phase 14 shipped a contracted per-mode shell map that no shipped mode ever executed, behind a switch that destroyed content tabs on every second visit to a mode, with both of its gates green. The map was unreachable because the toggle called stock `switchPerspective` directly; the destruction is stock restoring a stale saved layout while Lumino unparents everything absent from it. Neither is visible to a check that reads text, which is why the last task of this plan is behavioural rather than another derivation.
Output: the exemption seam, the reroute, `ensureInArea`, the launch-order move, the corrected text gates, and a live gate whose self-test reproduces the unfixed tree.

STATE AT WRITING (2026-09-06): tasks 1 and 2 are already present as UNCOMMITTED edits in the working tree, written by the agents that diagnosed them, and task 3's gate file and registry rows are present too. Executing this plan is therefore verify-and-commit, not write-from-scratch, for everything except the live RUN in task 3 — which no agent has done, and which is the only step that produces evidence rather than argument. Do not rewrite what is already there on the assumption it is missing.
</objective>
