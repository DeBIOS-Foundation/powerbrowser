<objective>
**As a** downstream brand author, **I want to** write one identity value into `configuration.toml`
and have one command turn it into a real Gecko build surface, **so that** I can prove the whole
rebrand path works end to end before I trust it with the rest of my brand.

This is the tracer slice for Phase 2. It wires ONE path through every layer the phase touches —
manifest file, vendored parser, schema table, unknown-key rejection, validation, emitter, writer,
byte comparison against the Phase 1 hand-written file — and stops there. Four of the five build
surfaces and the two-layer merge are deliberately absent; they are expansion tasks in later plans
that build out from this proven slice.

Purpose: prove the architecture end to end on one file before nine more layers are committed on
top of it. If the parse-validate-emit-compare chain cannot reach byte-identity for the simplest of
the five targets, that is the moment to find out.

Output: a vendored TOML parser with recorded provenance, `configuration.toml` carrying Power
Browser's full identity, the one schema table, `scripts/generate.mjs` with a working
single-emitter pipeline, and a git-ignored `generated/` root.
</objective>
