<objective>
Retarget the VER-02 runtime layer so the six-surface identity check reads expectations from configuration.toml instead of its hardcoded VARIANTS descriptor, and prove it live against the existing dev build.

Purpose: VER-02 success criterion 2 — runtime verification checks six branding surfaces by exact equality against the built artifact with expectations from configuration.toml. scripts/verify-branding-identity.mjs already drives the built binary through six exact-equality surfaces with a coverage guard and positive controls, but its expected values are constants in the VARIANTS descriptor (brandFullName 'Power Browser Dev' / 'Power Browser'), so a downstream's manifest can never satisfy it and a wrong constant agrees with itself. This plan re-sources those expectations from the manifest while keeping every surface, the guard, and the controls.

Output: Retargeted checker with extended self-test, updated preflight section 4, live dev-variant run green, release-variant drill staged.
</objective>
