## Flagged assumptions (no silent drops)

1. GEN-01 concurrency probe (unresolved edge): if generate.mjs is interrupted mid-write or two copies run against one tree in parallel, no atomicity is promised beyond today's two-pass emit-all-then-write, which guarantees only that a *reported* failure leaves the tree untouched — an OS kill inside the write loop can leave partial files. Mitigation carried by this plan: BUILD.md orders a fresh generate before every configure and generate --check reports stale files, so a partial tree is always detected, never built on silently. Parallel writers remain unsupported (single-writer tool).
2. brand.dtd scope correction (RESEARCH open question 1): the GEN-01 success criterion names brand.dtd, but the pinned ESR tree holds no brand.dtd under browser/branding/ and nothing references chrome://branding/locale/brand.dtd. Recommendation: strike brand.dtd from the criterion and emit ftl plus properties only. User rules at review; this plan emits no brand.dtd either way.
