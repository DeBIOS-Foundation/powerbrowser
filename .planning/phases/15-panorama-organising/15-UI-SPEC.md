# Phase 15 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note.** This phase builds GUI-08: a freeform Panorama canvas
(free drag, corner resize, auto-box on canvas drop, zoom, ungrouped tray)
plus a canvas/tree toggle over identical SQL-persisted group data, inside
the organising main-area slot that Phase 14 left as a placeholder. PNG
last-view snapshot thumbnails on cards. Canvas reads/writes only via the
single chrome-side writer path; sessionstore stays restore-authoritative
(never sessionstore-coupled — Bugzilla 1221050). Piles and type-anywhere
search ship only if cheap, else explicitly deferred. Never fork/patch
Theia core; never modify Gecko outside the 2 hook-only patches.

**Binding constraints.** The 13-01 spike verdict RED still binds: the tab
strip **STAYS TOP** — no contract below moves, filters, or re-skins the
strip, and choosing a tab never hides other tabs. The 14-02/14-03
organising placeholder slot (heading, body, "Back to Browsing") is
**removed** by this phase and replaced by the canvas/tree surface; its
copy is retired, not reused. Sketch 002 organising view is the visual
reference; the Panorama research note is the interaction authority.

**Inherits from 14-UI-SPEC** (do not contradict): design system `none`,
spacing ramp, typography delegation (3 sizes / 2 weights), color tokens,
60/30/10 split, focus idiom, motion baseline, copy rules (product named
"Power Browser", plain language, real on-screen next step, no internal
identifiers), mode names **"Coding"** / **"Browsing"** / **"Organising"**,
tabs invariant asserted by the status-bar chip. This spec states only
what is net-new or extended; unmentioned 13/14 contracts stand unchanged.

## Spacing Scale

Declared values (all multiples of 4). Sketch `--space-*` ramp adopted verbatim
from 13/14-UI-SPEC; `12px` is a declared step, not an exception.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, card-text gaps |
| sm | 8px | Card gaps inside boxes, toolbar-internal gaps |
| md-gap | 12px | Group-box padding, tree-row padding, tray padding |
| md | 16px | Canvas host padding, error-bar padding, dialog content |
| lg | 24px | Empty-state vertical rhythm (heading ↔ body ↔ button) |
| xl | 32px | Toolbar control hit area (32×32), tree-row min-height |
| 2xl | 48px | Not used in Phase 15 (reserved) |
| 3xl | 64px | Not used in Phase 15 (reserved) |

Fixed geometry (prescriptive): tab card **160px wide**, thumbnail
**160×90** (16:9, `object-fit: cover`), `radius-sm` (4px) on cards,
boxes, and tree rows. Group box minimum **200×144** (fits header plus
one card); box positions are user pixels, never snapped. Corner resize
handle **16×16** hit area (visual 12px grip, bottom-right corner only).
Ungrouped tray **144px tall**, fixed to the bottom of the organising main
area. Hairline borders `1px var(--color-border)` throughout.

Exceptions:

| Exception | Value | Why it stands |
|-----------|-------|---------------|
| Group-box position and size | user pixels, not scale | Pixel-free positioning is the locked Panorama mechanic — snapping to the scale would reintroduce the grid the research note forbids |
| `radius-full: 9999px` | non-scale | Pill token from the locked sketch theme; unchanged from Phase 13 |
| Canvas pan/zoom transform | CSS pixels + scale factor | The canvas layer scales under a transform; the contract fixes range and duration only (see Interaction Contract) |

## Typography

Theia side is delegated — the table below binds the delegation to exact
rendered sizes (3 sizes, 2 weights). No `font-size` / `font-weight` literal
may appear in `@powerbrowser/*` that is not one of these three sizes.

| Role | Size | Weight | Line Height | Applies to |
|------|------|--------|-------------|------------|
| Body | 14px | 400 (600 when active-group) | 1.5 | Group-box titles, tree group headers, empty-state body, error-bar text, dialog body |
| Label | 13px | 400 | 1.4 | Card titles, tree tab rows, toolbar buttons, toggle segments (600 when active segment) |
| Caption | 12px | 400 | 1.5 | Card URI captions (`--theia-code-font-family` mono), tray label + tray empty caption, zoom-level readout |

600 (semibold) is reserved for exactly three selection families, nothing
else: **(a)** the active toggle segment — mode toggle (carried) and the
canvas/tree toggle (net-new); **(b)** the current-setup / current-mode
marked row (carried from Phase 14); **(c)** the active-group title — group
box on canvas and group header in tree. Card titles, tree tab rows, and
inactive group titles never set 600; tree tab selection is a
surface-raised wash only. There are no headings above 14px in this phase.

## Color

Locked sketch theme (`sources/themes/default.css`), genuine 60/30/10 split by
painted area. Identical tokens to Phases 13/14; only the usage rows grow.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1c1b22` (`--color-bg`) | Canvas field, tree background, organising main-area background |
| Secondary (30%) | `#2b2a33` (`--color-surface`) fills, `#35343f` (`--color-surface-raised`) hover, `#3f3e4a` (`--color-border`) hairlines | Group boxes, tab cards, tray, toolbar, tree rows; hover raises; box/card hairlines |
| Text | `#fbfbfe` (`--color-text`) primary ink, `#9a99a8` (`--color-text-muted`) secondary ink | Titles, captions, tray label, inactive segments |
| Accent (10%) | `#00a6f5` (`--color-primary`), hover `#0090d4` | See reserved-for list below — nothing else |
| Success | `#8ad38a` | Lock glyph only (carried; no new success surface) |
| Destructive | `#ff848b` (`--color-danger` from the locked theme) | **Close Group confirmation only** — confirm button + dialog warning marker |

**Accent reserved for — exhaustive list (items 1–4 carried from Phase 14, items 5–7 net-new):**

1. Address-pill focus border/ring.
2. Active mode-toggle segment ink (never fill) + 600.
3. Keyboard-highlighted suggestion row wash.
4. Current-setup / current-mode selected-row marker plus the reserved 600.
5. Canvas/Tree toggle active segment ink (never fill) + 600.
6. Active-group marker — canvas: group-box border + title 600; tree: group-header marker + name 600 (planner picks border vs check-glyph per view consistent with item 4; never both in one view).
7. Valid drag-drop target outline (box border or tray edge) while a drag is over it; cleared on drop or cancel.

Nothing else. Accent must never be used as a general fill, thumbnails
carry no accent treatment, and no second brand hue may be introduced.

### Contrast

Unchanged pairings from 13/14-UI-SPEC (`#fbfbfe` on `#1c1b22` ≈ 16:1;
`#fbfbfe` on `#2b2a33` ≈ 13:1; `#9a99a8` on `#2b2a33` ≈ 5:1 — AA for
secondary text and captions). Muted ink must never be the sole carrier of
the active-group state (600 + accent border carry it too) or of the empty
tray caption's meaning (the "Ungrouped" label plus tray frame carry it).
`#ff848b` on `#2b2a33` ≈ 5:1 — the Close Group control pairs destructive
ink with its explicit label; colour is never the sole carrier (label +
confirmation step carry it).

### Focus

Every Phase-15 control (toggle segments, New Group, zoom buttons, group
titles in edit mode, group close buttons, error-bar Retry, tree rows and
group headers, cards via roving tabindex within their box/tray) shows a
visible focus indicator:
`outline: 2px solid var(--color-primary); outline-offset: 2px`
(WCAG 2.4.7 / 2.4.11, same idiom as 13/14-UI-SPEC).

### Motion

Baseline `transition: all 0.15s ease` on every interactive element
(sketch-locked, carried). Canvas specifics: the dragged card follows the
pointer directly (no transition while dragging, `opacity: 0.7`); drop
auto-box and join animations run ≤150ms; zoom transforms run ≤150ms;
semantic dive (card click opens its tab) uses the stock tab-open path with
no authored animation; `prefers-reduced-motion` renders every canvas
change instantly. Group data paints synchronously-feeling: local SQL
reads paint with skeleton boxes until first data (see UI Considerations),
never a spinner.

## Interaction Contract (GUI-08, net-new)

### Slot and toolbar — the placeholder is gone

- The organising main area hosts a toolbar row above the view: **[Canvas |
  Tree] segmented toggle | "New Group" button | zoom cluster (canvas
  only)**. The zoom cluster is hidden in tree view (zoom is meaningless
  there) — hidden, not disabled, so the toolbar never shows a dead
  control. The Phase-14 placeholder panel is removed with its slot; none
  of its copy survives.
- Canvas and tree are two views over one in-memory group model fed by the
  single chrome-side writer path. Flipping the toggle never reloads,
  never loses selection: the active group and the New Group draft (if
  any) survive the flip. A flip is never destructive and never needs
  confirmation.

### Canvas geometry — pixel-free, header-drag, corner-resize

- Group boxes are free-floating named boxes on one 2D field. No snap, no
  grid, no auto-fit, no auto-size: boxes sit at user pixels and resize
  only by the corner handle. Moving is header-drag (title bar strip);
  resizing is the bottom-right corner handle (16×16 hit area); card
  bodies are drag sources for tabs, never move handles.
- A box renders: header (title + close ×) over a card area. Cards beyond
  the box's current size scroll **inside** the card area (vertical);
  overflow never resizes the box and never spills onto the field.
- When box content exceeds the viewport the canvas host scrolls natively;
  zoom-out reveals more field. No marquee selection, no middle-drag pan,
  no custom scrollbar is authored.
- Clicking a box header or field background marks that group active
  (accent border + title 600, persisted as the active group); opening a
  tab marks its group active. Active-group state never filters or hides
  the tab strip — the strip stays top with all tabs per the RED binding.

### Auto-box on drop — the primary grouping gesture

- Dropping a tab card onto another card auto-draws a box containing both.
  Dropping a card onto empty field auto-draws a box around it. Dropping
  into an existing box joins that box. Dropping into the tray ungroups
  the tab. Every drop paints optimistically and persists through the
  single-writer path; on write failure the save-error bar appears and the
  painted change is reverted.
- During a drag the valid target shows the accent outline (item 7); the
  dragged card renders at `opacity: 0.7` and follows the pointer. `Esc`
  cancels the drag with nothing moved and nothing persisted.

### Zoom and dive

- Zoom range **25%–200%** in fixed steps with **100%** reset; the readout
  caption shows the level. Zoom scales the canvas layer transform only —
  card data and box bounds are untouched, and thumbnails scale by CSS
  (no re-capture on resize or zoom).
- Clicking (or Enter on a focused) card opens its tab — the semantic
  dive. Opening never closes, moves windows on, or detaches any tab.

### Ungrouped tray — always visible, bottom-fixed

- The tray is a 144px fixed bottom strip: "Ungrouped" caption label plus
  horizontally scrolling 160px cards (same card contract as canvas).
  Tabs with no group live here and here only. The tray is always
  rendered — it is the stable drop target for ungrouping — with the
  contracted empty caption when it holds zero tabs. It never grows its
  host; beyond its width it scrolls horizontally.

### Tree — identical data, vertical stacked lists

- Tree view renders each group as a section: header (title + tab count +
  close ×) over stacked tab rows (title 13px + mono URI caption 12px,
  32px min-height rows, ellipsis with full text in `title` tooltip). No
  thumbnails in tree — that is the canvas's job, not a missing state.
- Tree carries the same affordances as canvas: active-group marker +
  600, double-click rename with identical rules, header close × with the
  identical confirmation, empty-group hint for zero-tab groups. Row
  order and membership always match the canvas; any mismatch is a defect,
  never a second store's opinion.

### Tab cards — PNG snapshots with a text fallback

- A card renders its PNG last-view snapshot (160×90 cover) over its
  title (13px, ellipsis + tooltip) over its URI caption (12px mono,
  ellipsis + tooltip). A card with no snapshot yet — or whose snapshot
  failed — renders the title + URI block alone: never a broken-image
  glyph, never a spinner. Snapshots fill in when captured; the text
  block paints first so cards are never blank frames.
- Cards are keyboard-focusable with roving tabindex inside their
  box/tray; Enter opens the tab. Long titles/URIs truncate with
  ellipsis; full text lives in the `title` tooltip.

### Close group — the only destructive action

- The header × opens the contracted confirmation. Confirming closes
  exactly that group's tabs and removes the box; the flash confirms.
  Cancelling changes nothing. If the closed group was active, activity
  passes to the next remaining box or to none — never to a removed box.
  Closing the last box lands on the contracted empty-canvas copy.
