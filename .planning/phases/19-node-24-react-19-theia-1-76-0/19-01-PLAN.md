A command marked LONG (`yarn build`, a live row, a capture) runs one at a time:
1. `mkdir -p .planning/phases/19-node-24-react-19-theia-1-76-0/logs`. Confirm that
   `git check-ignore -q` on the log path exits 0 (`*.log` is ignored).
2. Run the pgrep line from the standing rules.
3. Launch it as one Bash call with `run_in_background` set, wrapped like this:
   `{ s=$(date +%s); {command}; rc=$?; echo "PHASE19_WALL_SECONDS=$(( $(date +%s) - s ))"; echo "PHASE19_EXIT=$rc"; } > "$L" 2>&1`
4. Wait for the completion notice. After an interruption, wait with a Monitor until-loop on
   `^PHASE19_EXIT=`, never with a fixed sleep.
5. Read `tail -n 2 "$L"`, then `tail -n 60 "$L"`. If the process ended with no `PHASE19_EXIT=`
   line, the run was killed, and that is a failure.
