    **New function `confirmDialogs(src)`**, placed beside `derivedDialogClasses`. It takes the

    scoring on the same messages.

    `derivedDialogClasses(rawSrc)` returning an array of
    `{ binding, classes }` — one entry per dialog from `confirmDialogs()`, where `classes` is
    every class name matched by a binding-anchored pattern built from that dialog's own binding
    (`new RegExp('\\b' + binding + '\\.addClass\\(\\s*\'([^\']+)\'\\s*\\)', 'g')`). A dialog with
    no binding gets `classes: []` and is flagged by the assertion below, because a class cannot
    be attributed to a construction that is never bound.

    **The destructive-ink assertions**, replacing the three-branch length check:

      class.
