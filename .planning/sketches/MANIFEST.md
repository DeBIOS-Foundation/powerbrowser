# Sketch Manifest

## Design Direction

Quiet Firefox-fresh dark, IDE-consistent: deep dark surfaces, muted
secondary text, one restrained blue accent. Browser chrome reads as a
native Theia citizen, not a skinned-on browser. Dense but calm.

## Reference Points

Firefox tab strip + address bar (tab feel, tear-off, tiles page);
Theia shell regions (menu bar, activity bar, side panels, main tab
bar, status bar) as the path-of-least-resistance constraint.
