## Design Direction
Quiet Firefox-fresh dark, IDE-consistent. Top chrome bar, mode-driven
shell with relocating tab strip, Panorama canvas for organising.

## Key Decisions
Layout: chrome bar as toolbar-like contribution above/below the Theia
toolbar; strip top in browsing, IDE-docked in coding. Palette:
neutrals + one restrained blue. Typography: system sans, mono for
URIs. Spacing: 4px base. Interaction: 0.15s baseline motion; freeform
canvas drag/resize/auto-box; tabs invariant across modes.
