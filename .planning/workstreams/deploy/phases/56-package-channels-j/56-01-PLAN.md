## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tree → binary cache | the flake hash in the bot PR decides what users install; a stale hash installs the previous release |
| release tarball → repack copies | the disable key must move exactly one way (tarball clean, repacks disabled) |
