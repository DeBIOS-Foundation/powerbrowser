## Trust Boundaries

|----------|-------------|
| build artifact → sign job | bytes cross from the unprivileged runner into the only job holding the MAR key |
| MAR bytes → published Release | signature plus attestation decide what every updater trusts |
| App token → tag + Release | a scoped token creates the tag the ruleset reserves for the bot |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-49-10 | Tampering | a swapped sign/verify order shipping an unverified MAR | high | mitigate | The row asserts gate, then sign, then verify, then upload; a swap is red naming the step order. |

| T-49-12 | Spoofing | a stale approval publishing old bytes | medium | mitigate | The sign job exits when a newer Release exists; the equality check runs after attest and before the single publish. |
