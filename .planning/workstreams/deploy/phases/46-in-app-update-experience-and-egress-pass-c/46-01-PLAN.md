## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| update service → shell observer | `subject`/`status` arrive from Gecko's own service; subject may be null (cant-apply) |
| frontend → handleShellMessage | kind strings arrive over the group actor; only the three new kinds plus the four old ones are admitted |
| shell → restart | `eRestart` quits the whole application; must run the same observers as any quit |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-46-01 | Tampering | update observer subject | medium | mitigate | Null-guard before QueryInterface; mapping function total over status strings; never throws. The read-only-dir plant (plan 46-03) exercises the null-subject path. |
| T-46-02 | Elevation of Privilege | restartToUpdate | medium | mitigate | Copies requestRestart exactly: announce quit-application-requested (cancellable by leave prompts/flush) before eRestart. No silent restart. |
| T-46-03 | Tampering | kind confusion (stray kind executes) | medium | mitigate | Unknown kinds return {ok:false} via the default case; the shell-request-kinds row asserts set equality so a stray kind on either side goes red. |
| T-46-04 | Spoofing | appUpdate push sender | low | mitigate | Push rides the existing PowerBrowserWebTabState path behind the groupSenderIsTheia wall; no new channel, no new origin. |
| T-46-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package. |
