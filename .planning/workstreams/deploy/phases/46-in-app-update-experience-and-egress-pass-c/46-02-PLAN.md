## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell push → client render | `status`/`version` arrive from chrome; the client renders only contracted strings keyed by status, never the raw values as sentences |
| user click → shell kind | Restart now / Check again clicks issue the three kinds over the actor channel behind the sender wall |
| copy module → row | The row derives what the module declares; a new string is red until covered |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-46-05 | Information Disclosure | version interpolation | low | mitigate | Version renders inside the contracted ready sentence only; raw service strings never reach the UI. The shape row rejects dotted keys and caps tokens in every string. |
| T-46-06 | Denial of Service | repeated error prompts | low | mitigate | Once-per-session flag: a failing checker cannot trap the user in a prompt loop. |
| T-46-07 | Tampering | second literal site | low | mitigate | The row asserts the client imports the copy module; a literal sentence in the client goes red. |
| T-46-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package. |
</threat_model>
