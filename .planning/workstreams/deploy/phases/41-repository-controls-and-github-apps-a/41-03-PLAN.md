    - `events(wf)`: `on` given as a string, an array or a map becomes a Set of event names.

    Rules:
    1. No `schedule` event in any file.
    2. Runner placement.
       - A job is hosted when it has exactly one label matching `^(ubuntu|windows|macos)-[\w.-]+$`.
       - A job is legion when its labels include `legion`.
       - Any other `runs-on` is red, including a bare `self-hosted`: legion carries the default self-hosted, linux and x64 labels, so such a job would reach it.
       - Jobs with a job-level `uses:` have no `runs-on` and are exempt.
       - A legion job must be in `release.yml` with a job id matching `^(build|matrix)-`. It must have no `environment` key, no `secrets.` substring in its JSON-serialised job or the workflow-level `env`, and no `secrets: inherit`.
