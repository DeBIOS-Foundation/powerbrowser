<objective>
Turn off language-pack updates and pin the update-cadence prefs to upstream defaults by a gate
(UPD-25).

Purpose:
- The release is en-US only (PKG-09), so the upstream default `app.update.langpack.enabled=true` (browser/app/profile/firefox.js:175) only adds an AMO lookup on each update.
- Update cadence and prompting stay at upstream's tested defaults. Leaving `app.update.interval` unset gives the 21600 s timer from `nsUpdateService.manifest:1`.
- The row derives the pref set from the generator, so a future emitter edit that sets one of the five cadence prefs goes red.

Output: the langpack pref in both variants, plus `scripts/verify-update-prefs.mjs` with two quick rows.
</objective>
