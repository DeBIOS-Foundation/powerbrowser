<objective>
Make "patches are regenerated, never text-edited" (CLAUDE.md) a gate.

Purpose: a hand-edited hunk body without recomputed blob hashes degrades `git apply --3way` into
a silent no-op. `regenerate-patches.sh --check` re-derives every tracked patch from the applied
`upstream/` and byte-compares it, so any hand edit goes red naming the patch. Write mode is the
only sanctioned way a patch changes.

The command diffs against `HEAD` (`git -C upstream diff HEAD --abbrev=10 -- <+++ b/ paths>`), not
the worktree alone. apply-patches.sh's `--3way` stages its result into the index, so the
worktree-only diff that SUMMARY correction 7 names is 0 bytes (RESEARCH Pitfall 1). The `HEAD`
form reproduced all four tracked patches byte-for-byte.

Output: `scripts/regenerate-patches.sh`, two quick rows, and the rebase-upstream.sh hook.
</objective>
