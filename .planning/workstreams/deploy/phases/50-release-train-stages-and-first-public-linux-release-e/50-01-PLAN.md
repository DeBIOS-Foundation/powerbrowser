## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dispatcher input to legion shell | merge_sha arrives from the train dispatch and reaches git plumbing in release.yml |
| clock or bot App token to workflow dispatch | the dispatch call needs Actions scope; a wrong token 403s or over-grants |
