<objective>
Gate the Glean crash ping on consent with a hook-only patch, and prove with a reporter-enabled layer-3 run that nothing reaches the crash-ping host before consent.

Purpose: TEL-09's fail-open is precisely located — the native crash reporter reads the profile prefs.js consent pref and defaults to true on every absent/unreadable input, so a fresh profile uploads before any consent. The shipped branding default (uploadEnabled=false) is the wrong channel for the native ping, which never reads it. This plan adds the binary-side fail-closed default via the patch stack plus a layer-3 observation that proves it, with a positive control that proves the observation can go red. Nothing here flips the reporter on for shipped builds; the --disable-crashreporter literal stays until TEL-13.</objective>
