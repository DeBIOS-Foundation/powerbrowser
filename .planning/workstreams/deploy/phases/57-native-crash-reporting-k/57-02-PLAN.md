## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest → generated origin → baked ServerURL | one stated URL becomes two build inputs through derivation |
| public internet → Worker /submit | anyone with the shipped build knows the URL and can post |
| agent shell → Cloudflare dashboard | deploys and rules are owner-only; the tree carries none |
| collector gate → Worker gate | shared vocabulary must not drift between the two receivers |
